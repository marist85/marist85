# SMT III Nocturne HD Remaster Haptics

MelonLoader 모드로 전투 타격, 필드 피해, 인카운트에 게임패드 진동을 추가합니다.

## 기능

- 전투 타격: 노멀 200ms/35%, 위크 200ms/70%, 크리티컬 300ms/100%
- 다단히트 및 다중 대상 공격의 타격별 진동
- 플레이어가 받는 몬스터 공격도 노멀·위크·크리티컬 판정에 따라 진동


## 설치

SMT3NocturneHaptics.dll 을 게임의 `Mods` 폴더에 복사합니다. 기존 DLL이 있으면 게임을 종료한 뒤 교체하고, 같은 모드 DLL을 중복해서 두지 마세요.

필요 환경: Shin Megami Tensei III Nocturne HD Remaster, MelonLoader IL2CPP, XInput 호환 패드.
